### Linux复习

#### Linux 文件系统层次结构

```text
/ (根目录)
├── 🚀 boot/     (启动核心文件)
├── ⚙️ etc/      (全局系统配置文件)
├── 👥 home/     (普通用户主目录)
├── 👑 root/     (超级管理员主目录)
├── 📦 bin/      (基础用户命令)
├── 🛠️ sbin/     (系统管理员命令)
├── 🔌 dev/      (硬件设备文件)
├── 💾 media/    (自动挂载点: U盘/光盘)
├── 🔄 mnt/      (手动临时挂载点)
├── 📊 var/      (动态数据与日志)
├── ⏳ tmp/      (临时文件，重启易失)
└── 🧠 proc/     (内存虚拟文件系统: 进程与内核)
```

#### 实时监控

全局全部进程、3 秒刷新：`top -d 3`（`-d=delay` 刷新间隔）

只看指定用户进程：`top -u 用户名`（`-u=user` 指定用户）



#### 四个

1. **NFS**

   全称：Network File System

   中文：网络文件系统

   核心考点：基于 RPC、Linux 间远程目录挂载，无独立传输功能

2. **Samba**

   无缩写全称，项目名本身叫 Samba，底层协议 

   SMB/CIFS

- SMB：Server Message Block（服务器消息块）

- CIFS：Common Internet File System（通用互联网文件系统）

  核心考点：Linux 与 Windows 跨平台共享

1. **FTP**

   全称：File Transfer Protocol

   中文：文件传输协议

   核心考点：专门用于文件上传下载，是传输协议，不是挂载文件系统

2. **SSH**

   全称：Secure Shell

   中文：安全外壳协议

   核心考点：加密远程登录，附属 SSHFS 可挂载，不依赖 RPC
